## Project overview

Autostereogram generator web app (Stereogen). Users upload a photo, the server estimates depth, and the browser generates the stereogram.

## Architecture

- **Backend**: Python FastAPI (`server/main.py`), single endpoint `POST /api/depth` using Depth Anything V2 Base (Hugging Face transformers pipeline)
- **Frontend**: Vanilla HTML/JS/Canvas (`frontend/`), no build step, no framework
- **Stereogram algorithm**: Thimbleby et al. 1994, processes rows from center outward (`createStereogram` in `app.js`)
- **Patterns**: 10 pre-generated tileable PNGs in `frontend/patterns/`, generated by `generate_patterns.py`

## Key files

- `server/main.py` — FastAPI app, depth estimation endpoint, serves frontend static files
- `frontend/app.js` — Upload logic, stereogram generation algorithm, UI interactions
- `frontend/index.html` — Single page layout
- `frontend/style.css` — Styles
- `Dockerfile` — CPU-only PyTorch, model downloaded at build time

## Running

```bash
cd server && uvicorn main:app --reload
```

## Commands

- Run server: `cd server && uvicorn main:app --reload`
- Regenerate patterns: `cd frontend/patterns && python generate_patterns.py`
- Docker build: `docker build -t stereogen .`
- Docker run: `docker run -p 8000:8000 stereogen`

## Code conventions

- Frontend: vanilla JS, no transpilation, no modules
- Backend: Python, type hints not enforced, minimal dependencies
- Language: UI in French, code/comments in English
